The handler finishes its backend call and response before its deferred `l.Done()` closes that channel. See [internal/direct/authority.go:527–584](https://github.com/Kchymet/agent-multiplexer/blob/c0e06c5fcee261ef795ad37f4095a323a53b45fe/internal/direct/authority.go#L527-L584), [internal/direct/server.go:594–598](https://github.com/Kchymet/agent-multiplexer/blob/c0e06c5fcee261ef795ad37f4095a323a53b45fe/internal/direct/server.go#L594-L598), [internal/direct/server.go:671–700](https://github.com/Kchymet/agent-multiplexer/blob/c0e06c5fcee261ef795ad37f4095a323a53b45fe/internal/direct/server.go#L671-L700), [internal/direct/authority.go:762–824](https://github.com/Kchymet/agent-multiplexer/blob/c0e06c5fcee261ef795ad37f4095a323a53b45fe/internal/direct/authority.go#L762-L824).
