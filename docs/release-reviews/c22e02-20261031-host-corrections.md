[Dependency authority source](https://github.com/Kchymet/agent-multiplexer/blob/76fd50e16aac42b877afa2b93608fd6cdd0a32fb/internal/access/authority.go#L983).

**Observed ordering:** `publish` swaps the registry/view while holding the lease lock exclusively, then closes invalidated-key watchers under `watchMu`. Watch registration checks the view and registers under that same watcher mutex (`authority.go:1088–1135`). This avoids the check/register missed-invalidation window. After a successful Rotate/Revoke return, subsequent validity checks see the replacement/revocation, and old-key watchers have been closed. A check that started before publication can still finish using its old snapshot; authorization of an effect is a separate boundary.

**Important limit:** registry disk commit happens **before** `publish` waits for leases (`:975–978,1125–1134`). The first 50 ms use nonblocking publication attempts; new leases then yield for up to 100 ms each; after two seconds the writer takes the blocking lock (`:1137–1201`). This prevents starvation once existing leases end; it is not a two-second revocation deadline. A stalled in-flight lease/storage operation can delay publication and watcher closure beyond any fixed limit. Concurrent checks can still observe the previous published state before the revocation call returns, even after the registry disk write. Thus the supported guarantee is publication/denial by successful local call completion, **not** a proven <=30 s bound from SaaS commit, request arrival, or local disk commit. Host acknowledgement and the separately proposed SaaS SLA must remain distinct. The `WithValid` comment saying revocation cannot “commit” inside its lease should be understood as publication/effect ordering, not the newly separated disk-commit instant.

**Observed existing tests:** `authority_convoy_test.go:55,140,185,200,206` cover progress behind leases/writer file I/O, measured lease wait, and short/long overlapping lease progress; they check rejection after writer return. These tests pass in the inspected package CI, but do not prove an absolute deadline under a stuck lease. No additional provocative timing test was attempted.
